# Teamwork

Teamwork runs a request through roles and review phases on a shared board.

Open **Open team board** from the command palette, describe the work, pick a team and how much oversight you want, then create the board. Creating a board spends nothing. Start the lead when you are ready, and start other members as the work needs them.

Phases move forward only with evidence and verdicts. When a run needs you, approve it or stop it from the board. A run over budget stops until you resume it with a larger budget. Cost is a measured estimate, not a billing ceiling.
